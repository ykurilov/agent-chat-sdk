# Записи об изменениях (changesets)

Каждое изменение, которое увидят приложения, описывается отдельным файлом в этой папке.
Файл создаёт тот, кто делает изменение, в том же коммите, что и код: `pnpm changeset`
(или руками по шаблону ниже). При выпуске (`pnpm release`) файлы сливаются в `CHANGELOG.md`
пакетов, а сами удаляются.

Читателя записи представляйте так: это агент, который обновляет чужое приложение и видит только
этот текст. Всё, что ему нужно сделать, должно быть в записи. Полные правила — в
[RELEASING.md](../RELEASING.md).

## Шаблон обычной записи

```md
---
"@ykurilov/agent-chat-react": minor
---

Что изменилось для человека, простыми словами: одно-два предложения.
```

Имя файла — любое короткое, латиницей: `.changeset/agent-tabs.md`. В шапке — пакеты, которых
касается изменение, и тип: `patch` (исправление), `minor` (новая возможность), `major`
(ломает существующие приложения; пока версия 0.x — тоже `minor`). Версия у всех пакетов одна:
любая запись поднимает её у всех, но в `CHANGELOG.md` появится запись только в перечисленных пакетах.

## Шаблон записи с ломающим изменением

````md
---
"@ykurilov/agent-chat-server": minor
"@ykurilov/agent-chat-react": minor
---

**Ломает приложения:** адрес чата теперь задаётся в `basePath`, а не в `route`.

Что изменилось: одно-два предложения простыми словами и зачем.

### Как обновить приложение

1. В `server/index.ts` замените параметр:

   Было:

   ```ts
   createChatHandler({ route: "/api/chat", storage });
   ```

   Стало:

   ```ts
   createChatHandler({ basePath: "/api/chat", storage });
   ```

2. Если в приложении есть свои тесты, которые вызывают `route`, поправьте их так же.
3. Проверка: `pnpm typecheck` проходит, чат открывается и отвечает.
````

Раздел «Как обновить приложение» для ломающего изменения обязателен: код было/стало и точные шаги
по порядку, с именами файлов, где искать. Без него запись не принимается.
