# Простой вид работы агента

Приложение выбирает, как показывать работу агента в ленте. Свойство экрана чата `workView` меняется на лету, без
перезагрузки и без новых запросов.

- **`detailed`** (по умолчанию) — как раньше: блоки «Думал N сек», строки инструментов с входом и выходом.
- **`simple`** — для людей, которым код не нужен:
  - пока ход идёт — одна живая строка с текущим шагом: «Рисую календарь…»;
  - после хода шаги и размышления свёрнуты в «Сделано N шагов ›». В раскрытии — список понятных фраз, без кода,
    аргументов, путей и результатов инструментов;
  - «Думал N сек» нет;
  - как обычно видны: ответ, виджеты, картинки, видео, схемы, файлы, события приложения, подтверждение опасного
    действия (`needsApproval`), ошибки, кнопки под сообщением;
  - текст между шагами видно, шаги между кусками текста свёрнуты отдельно;
  - одинаковые фразы подряд — одна строка с числом: «Поискал в интернете ×5». «Сделано N шагов» считает все вызовы,
    вместе с повторами;
  - длинная фраза обрезается до 120 знаков с «…», переводы строк в ней становятся пробелами.

## Подключение

```tsx
import { ChatWorkspace } from "@ykurilov/agent-chat-react";
import type { StepPhrases } from "@ykurilov/agent-chat-react";
import { webToolStepPhrases } from "@ykurilov/agent-chat-web-tools/labels";
import { memoryStepPhrases } from "@ykurilov/agent-chat-memory/labels";

const stepPhrases: StepPhrases = {
  ...webToolStepPhrases,
  ...memoryStepPhrases,
  write_file: ({ input }) => {
    const name = (input as { path?: string } | undefined)?.path?.split("/").at(-1);
    return name ? { running: `Пишу ${name}`, done: `Написал ${name}` } : undefined;
  },
  check_app: { running: "Проверяю приложение", done: "Проверил приложение", failed: "Проверка не прошла" },
};

<ChatWorkspace api="/api/chat" skin={tandemSkin} workView={simple ? "simple" : "detailed"} stepPhrases={stepPhrases} />;
```

То же свойство есть у `AgentChat` и `AgentPanel`.

## Фразы шагов

`stepPhrases` — имя инструмента → фразы. Фразы бывают готовые (`{ running, done, failed? }`) или функция от вызова
`{ toolName, state, input?, output? }`, которая отдаёт их часть или `undefined`.

- Многоточие в живой строке ставит чат сам. Своё многоточие в конце фразы убирается.
- Вход и выход бывают не всегда: вход ещё пишется или скрыт правами (`toolDetails: false`). Функция должна давать фразу
  и без них — или вернуть `undefined`.
- Функция упала или вернула странное — чат не ломается, берётся следующая фраза по порядку.
- Функция получает и результат инструмента (`output`). Фраза не должна его пересказывать: только что сделано, без данных,
  путей и текста ошибок.

Порядок выбора: фраза приложения → фраза помощника → название инструмента (`title`) → общая фраза словаря («Работаю»,
«Сделал шаг», «… — не вышло»). Своё имя модели в живую строку не попадает: без фразы и `title` — общая фраза.

Встроенные пакеты дают свои фразы (русские и английские) во входе `./labels`. Приложение подключает их само:

| Пакет | Русские | Английские |
|---|---|---|
| `@ykurilov/agent-chat-web-tools/labels` | `webToolStepPhrases` | `englishWebToolStepPhrases` |
| `@ykurilov/agent-chat-memory/labels` | `memoryStepPhrases` | `englishMemoryStepPhrases` |
| `@ykurilov/agent-chat-history-search/labels` | `historySearchStepPhrases` | `englishHistorySearchStepPhrases` |
| `@ykurilov/agent-chat-background/labels` | `backgroundStepPhrases` | `englishBackgroundStepPhrases` |
| `@ykurilov/agent-chat-skills/labels` | `skillsStepPhrases` | `englishSkillsStepPhrases` |

Помощники (`HelperCallRow`) в простом виде — тоже шаг. Без своей фразы — по названию помощника (`title`, иначе
внутреннее имя): «Помощник «researcher» работает» / «закончил». Внутреннее имя человеку ничего не скажет — дайте помощнику
`title` или фразу по имени его инструмента `helper_<имя>`:

```ts
const stepPhrases: StepPhrases = {
  helper_researcher: { running: "Ищу статьи по теме", done: "Нашёл статьи по теме" },
};
```

## Значки шагов (с 0.69, скин 28)

В строке «Сделано N шагов» — ряд маленьких значков, по одному на шаг (больше 8 — «+N»). В раскрытом списке каждый шаг —
«значок + фраза», раздумья тоже: заголовок раздумья или «Думал N сек». В живой строке — значок текущего шага.

Значок — вид шага строкой (`StepIcon`): `thinking`, `read`, `edit`, `search`, `web`, `skill`, `mcp`, `image`, `video`,
`check`, `snapshot`, `run`, `memory`, `helper`, `task`, `tool`. Своему инструменту задайте его рядом с фразами:

```ts
const stepPhrases: StepPhrases = {
  edit_file: ({ input }) => ({ running: `Правлю ${pathOf(input)}`, done: `Правил ${pathOf(input)}`, icon: "edit" }),
  take_screenshot: { running: "Смотрю экран", done: "Посмотрел экран", icon: "snapshot" },
};
```

Нет `icon` — значок угадывается (`guessStepIcon`): инструменты пакетов SDK, MCP (`<префикс>__<имя>`), помощники
(`helper_*`), слова имени (`edit_file` — правка, `read_file` — чтение, `run_tests` — проверка), иначе общий (`tool`).

## Заголовки раздумий (с 0.69)

Вместо «Думал 3 сек» — короткий заголовок: «Продумываю правила игры». Включается на сервере:
`createChatService({ thoughtTitles })` (раздел «Значки шагов и заголовки раздумий» в
[getting-started.md](./getting-started.md)). Экран берёт заголовок сам — из метаданных ответа (`thoughtTitles`), в
простом виде (список и живая строка) и в подробном (`Reasoning.title`). Пока заголовка нет — «Думаю…»; не вышло —
прежняя подпись. Заголовок виден и без права `reasoning` (если не выключено `showWithoutReasoning: false`): сервер шлёт
пустое место раздумья — только у раздумья с заголовком — и заголовок, без текста; такое место в простом виде — шаг с
заголовком, в подробном не показывается.

## Подписи

Общие надписи — `labels.workView` (`ChatLabels`), частично: что не задано, берётся из русского словаря.
Английский — `englishWorkViewLabels` (уже входит в `englishLabels`).

| Поле | По-русски |
|---|---|
| `stepRunning` / `stepDone` | «Работаю» / «Сделал шаг» |
| `stepFailed(running)` / `stepFailedUnknown` | «Пишу файл — не вышло» / «Шаг не получился» |
| `stepUnfinished(running)` / `stepUnfinishedUnknown` | «Пишу файл — не закончил» / «Шаг не закончен» |
| `stepRepeated(phrase, count)` | «Поискал в интернете ×5» |
| `thinking` | «Думаю» |
| `thought(durationMs)` | раздумье без заголовка в списке: «Думал 4 сек», без времени — «Подумал» (0.69) |
| `moreSteps(count)` | скрытые значки ряда: «+3» (0.69) |
| `live(phrase)` | фраза с многоточием |
| `stepsDone(count)` | «Сделан 1 шаг», «Сделано 3 шага» |
| `helperRunning(name)` / `helperDone(name)` | «Помощник «X» работает» / «закончил» |

## Права и простой вид

Простой вид — только отображение, не права. Скрыть вход и выход от посетителя — по-прежнему права на сервере
(`toolDetails`, `reasoning`, `modelDetails`). Если вызовы скрыты правами, в простом виде их тоже нет; если скрыт только
вход — фраза строится по имени инструмента.

## Особые случаи

- **«Стоп» и обрыв.** Ответ закончился, а шаг так и не завершился — в списке «… — не закончил», с пометкой неудачи
  (`failed`). Живая строка гаснет вместе с ходом. Повтор и прерванный ответ раскладываются так же.
- **Ошибка шага.** В простом виде видна только тихая строка «… — не вышло» в свёрнутом списке, текста ошибки нет.
  Если инструмент просит человека что-то сделать («подключите календарь»), это должен сказать ответ модели — или
  приложение показывает такую ошибку само (событием приложения или виджетом).
- **Параллельные вызовы.** Живая строка показывает фразу вызова, который ещё идёт, а не того, что уже закончился.
- **Пустой текст между шагами** (модель начала писать и сразу позвала инструмент) группу шагов не разрывает.
- **Поправки на ходу и фоновые задачи.** Поправка — отдельное сообщение человека, как обычно. Карточки фоновых задач и
  служебные сообщения видны как обычно; инструменты проверки и отмены задач — шаги.
- **Длинные ходы.** Сколько бы шагов ни было — одна строка, список раскрывается по нажатию. Раскрытие помнит чат, как
  раскрытие мыслей.

## Для авторов скинов: `ChatSkin` v23

- `ChatSkin` поднялся с версии 22 до **23**: появилось необязательное `WorkSteps`.
- **Скин версии 22 работает без правок.** Без `WorkSteps` простой вид рисуется строкой `ToolCallRow`: «Сделано N шагов»
  (или живая фраза) в `title` и `toolName`, входа нет. В результате (`output`) — список понятных фраз строкой, по фразе на
  строку: скин покажет его как обычный результат вызова. Пока ход идёт, результата нет. Вид будет «технический» — для
  понятного вида добавьте `WorkSteps`.

`WorkSteps` получает `WorkStepsView`:

- `{ state: "live", phrase }` — живая строка, фраза уже с многоточием. Кнопок нет. Фраза меняется часто: диктору её не
  читать, а объявить один раз постоянное `labels.workView.live(labels.workView.stepRunning)` («Работаю…»).
- `{ state: "done", steps, count, open, onOpenChange }` — строка `labels.workView.stepsDone(count)` (`count` — все
  вызовы с повторами); по нажатию — список `steps[].phrase`. `failed: true` — шаг не получился или не закончен,
  отметить тихо. Фразы — только текст, до 120 знаков; длинное слово переносить (`overflow-wrap: anywhere`).

В Тандеме (`TandemWorkSteps`) живая строка — тихий текст с пульсирующей точкой (`data-work-live`), законченная —
как «Думал N сек»: кнопка со стрелкой и список (`data-work-step`, `data-failed`).


Версия 28 (необязательное, [skin-v28.md](./skin-v28.md)): `live.icon`, `done.items` (вызовы и раздумья со значками),
`done.icons` и `done.moreIcons` (ряд значков), `Reasoning.title`. В Тандеме значок живой строки заменяет точку, ряд
значков стоит рядом с «Сделано N шагов» (`data-step-icons`), у строк списка — свой значок (`data-step-icon`).
