# Схемы в ответах агента

Агент рисует схему текстом: пишет в ответе блок ` ```mermaid `. Экран превращает его в картинку-схему, которую можно открыть
на весь экран. Рисует отдельный пакет `@ykurilov/agent-chat-diagrams`; серверу он не нужен.

Без пакета и без `diagrams` блок остаётся обычным кодом, как раньше. Приложение без схем не получает ни байта mermaid.

## Включить

```bash
pnpm add @ykurilov/agent-chat-diagrams
```

```ts
// сервер: одна постоянная строка в инструкции агента
createChatHandler({ …, agent: { instructions: appInstructions, diagrams: true } });
```

```tsx
// страница
import { diagramsClient } from "@ykurilov/agent-chat-diagrams";
<AgentChat … diagrams={diagramsClient} />;
```

Строка инструкции (`diagramsInstructions` из ядра) просит рисовать схему блоком ` ```mermaid `, не больше 50 узлов, без ссылок, HTML и стилей.
Она не меняется от хода к ходу, поэтому кэш модели цел.

## Как это работает

- Пока ответ печатается и блок не закрыт, человек видит заглушку «Схема рисуется…». Когда блок закрыт, схема рисуется.
- Mermaid загружается отдельным куском при первой схеме. Пока схем нет, страница его не качает.
- Цвета берутся у скина (`ChatSkin.diagramColors`): сменил человек тему — схема перерисуется. Готовые схемы помнятся, лента не прыгает.
- Не получилось нарисовать (ошибка в тексте схемы, слишком длинная) — показан исходный текст блоком кода с подписью «Схему не удалось нарисовать, показан её текст».
- Пределы: не больше 20 000 знаков и 200 узлов. Больше — схема не рисуется.
- Клик по схеме открывает её в [окне просмотра](media-viewer.md): одна схема, векторная, с масштабом.
- Голосовой режим вместо блока говорит «схема на экране».

## Безопасность

Схему пишет модель, а модель можно подтолкнуть словами человека или чужой страницы. Поэтому mermaid работает в строгом режиме,
подписи — текстом, а готовый SVG ещё раз чистится: уходят `<script>`, `<foreignObject>`, `<a>` (текст остаётся), `<image>`,
внешние `<use>`, атрибуты `on…`, ссылки не на `#` и `style` с внешним `url(`. Чистка — `cleanSvg` из того же пакета: если
рисуете схему сами, пропускайте SVG через неё.

## Свой скин

Скин версии 13 в `AgentText` получает необязательные `renderDiagram(source, blockIndex)` и `onOpenDiagram(blockIndex, trigger)`.
Блоки находите той же функцией, что и слой поведения, чтобы номера совпали: `splitMermaidBlocks(markdown)` из `@ykurilov/agent-chat-react`.
`renderDiagram` возвращает `{ state: "streaming" }`, `{ state: "ready", svg, source }` или `{ state: "failed", source }`.
Цвета схемы отдаёт `diagramColors(dark)`; нет — рисовальщик берёт свои. Скин без этих частей показывает блок кодом.
Надписи — группа `diagram` словаря. Подробности — [договор](contracts/agent-widgets/react-and-skin.md).

Пример — `apps/demo` (сценарии `apps/demo/e2e/diagrams.spec.ts`).
