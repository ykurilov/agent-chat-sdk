# Мобильная клавиатура и оболочка приложения

Начиная с 0.87.10, `ChatAppViewport` размещает приложение в фактически видимой области браузера. Навигация остаётся сверху, чат получает оставшуюся высоту, а при открытии клавиатуры сокращается лента. Навигация и поле остаются в доступной области, даже если браузер сдвигает документ при фокусе. После размонтирования оболочка возвращает прежние стили документа и его позицию прокрутки.

`100dvh` в одиночку не заменяет эту оболочку: экранная клавиатура может уменьшать только `visualViewport`, сохраняя высоту layout viewport. SDK следит за геометрией видимой области и её смещением. Увеличение страницы жестом не считается открытием клавиатуры и не отключается.

## Подключение

Обновите установленные пакеты SDK одной версией. Вместо внешнего `h-dvh` и прокручиваемого контейнера вокруг чата используйте одну оболочку приложения:

```tsx
import { ChatAppViewport, ChatWorkspace } from '@ykurilov/agent-chat-skin-oduvanchik/chat';

export function AppShell() {
  return (
    <ChatAppViewport header={<AppNavigation />}>
      <ChatWorkspace api="/api/chat" />
    </ChatAppViewport>
  );
}
```

Свойства самого `ChatWorkspace` сохраняются. `header` принимает навигацию приложения. Внутри оболочки другие страницы могут прокручиваться в контейнере содержимого; у чата прокручивается собственная лента. Не оборачивайте чат ещё одним контейнером фиксированной высоты или внешней прокруткой страницы.

С Тандемом импортируйте `ChatAppViewport` из `@ykurilov/agent-chat-react` и передавайте свой скин как раньше. Для встроенного в страницу блока, который не занимает весь экран, оболочка не требуется: оба штатных скина ограничивают высоту по доступной области при вводе, не блокируя прокрутку чужой страницы. Полное управление высотой страницы и её навигацией принадлежит именно `ChatAppViewport`.

Размещайте оболочку около корня React, вне предков с `transform`, `filter`, `perspective` или `contain`, меняющих систему координат или обрезающих содержимое. Не задавайте корню оболочки свою высоту, позицию или transform. В приложении должен быть один владелец полноэкранной геометрии: уберите собственные обработчики клавиатуры, дублирующее вычитание её высоты и глобальную блокировку body, добавленные ради чата.

В HTML сохраните:

```html
<meta name="viewport" content="width=device-width, initial-scale=1, viewport-fit=cover" />
```

Не запрещайте масштабирование через `maximum-scale` или `user-scalable=no`. `interactive-widget=resizes-content` допускается в Chromium, но не заменяет обработку `visualViewport` в WebKit.

## Safe area и свой скин

Оболочка учитывает верхнюю и боковые safe area. Штатные скины сохраняют нижний отступ устройства при закрытой клавиатуре и снимают его, пока клавиатура занимает нижний край. Не прибавляйте `safe-area-inset-bottom` повторно вокруг композера.

Свой скин может подключить `useChatViewport(ref)` из `@ykurilov/agent-chat-react` к внешнему flex-контейнеру чата. Его высота должна быть ограничена родителем, а лента - иметь `min-height: 0` и собственную прокрутку. Hook не блокирует документ; в полноэкранном приложении используйте его вместе с оболочкой. Нижний padding композера читает `var(--agent-chat-safe-area-bottom, env(safe-area-inset-bottom, 0px))`.

На телефоне размер шрифта редактируемого поля должен быть не меньше 16 CSS px, чтобы фокус не вызывал дополнительное увеличение страницы в iOS. Штатные скины задают этот размер.

## Границы проверки

Дополнительный Safari-сценарий с настоящей экранной клавиатурой iOS Simulator находится в `apps/demo/tests/viewport/ios`; он работает через отдельное место с экраном на iMac.

Автоматические проверки геометрии моделируют изменение `visualViewport` в Chromium и WebKit. Они не являются проверкой физического iPhone, браузера Chrome на iOS, установленной PWA или Android-клавиатуры. Проверяйте эти режимы на целевых устройствах: открытие и закрытие клавиатуры, повторный фокус, поворот экрана, сохранение черновика, ручное чтение старой истории и возврат на другую страницу.
