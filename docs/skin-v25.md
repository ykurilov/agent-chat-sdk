# Для авторов скинов: `ChatSkin` v25

Что нового — реплика живого сотрудника в ленте. Эксперт ответил человеку из своих «Входящих», приложение положило ответ
в историю (`service.appendStaffMessage` или `flow.noteStaffReply`).

- `ChatSkin` поднялся с версии 24 до **25**;
- появился необязательный компонент `StaffMessage` (`StaffMessageView`: `text` — что написал сотрудник, `staffName` —
  его имя, может не быть). Рисуйте его со стороны агента, с подписью сотрудника;
- в словаре — `labels.notices.staffSaid(staffName)` («Сотрудник Ольга» / «Staff: Olga»).

**Скин версии 24 работает без правок:** реплика показывается ответом агента (`AgentMessage` + `AgentText`) с жирной
подписью из словаря. Скин Тандема свой `StaffMessage` пока не рисует.
