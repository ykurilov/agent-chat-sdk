# Для авторов скинов: ChatSkin v30

Добавление необязательное: скины v29 работают без изменений.

`Layout.empty?: boolean` - история успешно загружена и сообщений нет, ход не идёт, нет ошибки загрузки/отправки, отказа сервера или потери связи. Слой поведения передаёт значение из состояния чата, а не из DOM или содержимого ReactNode. При ожидании подтверждения в истории есть сообщение, поэтому приветствие не показывается. `feed` и `scrollRef` остаются прежними: лента должна оставаться смонтированной, `scrollRef` указывает на единственный прокручиваемый DOM-элемент.

`ChatLabels.welcome?: { title?: string; description?: string }` - надписи приветствия. Старые словари получают русские или английские значения по `locale`; приложение вправе заменить обе строки. Это не приветственное сообщение модели: текст не сохраняется и не отправляется провайдеру.

Одуванчик использует `ScrollArea` из DS и передаёт ему `scrollRef`. Между текстом и полосой прокрутки остаётся минимум 16 px даже с overlay-scrollbar. Поле ввода - отдельный непрокручиваемый footer. Внешнему приложению не следует оборачивать этот чат вторым ScrollArea.

## SandboxSkin v1: необязательные дополнения

`SandboxLayout.busy?: boolean` и `JournalList.busy?: boolean` - состояние реального хода из ленты. Это не запись журнала и не свидетельство выполнения конкретного инструмента. Список обращений перечитывается после конца хода. Скин может показать сферу работы, не добавляя вымышленных строк `model`/`tool` или стадий сценария. Старые скины игнорируют поля.
