# Договор скина, версия 32

Добавлен необязательный `ChatSkin.AnswerTextEditor`. Скины предыдущих версий работают без изменений. Пользовательский `answerEditing.renderEditor` не изменён; `SandboxSkin.AnswerEditor` - отдельный прежний контракт.

Новый компонент получает контролируемые `value`, `onValueChange`, `onSave`, `onCancel`, `canSave`, `saving`, необязательный текст `error` и React-узел `fields` приложения. Поле и кнопки сохранения/отмены выключены при `saving`; отмена закрывает окно без записи. Ошибка показывается с `role="alert"`, поля сохраняют содержимое. Компонент не отправляет запросы сам. Состоянием и запросами управляет слой React.

«Одуванчик» реализует слот через Dialog, Textarea и Button дизайн-системы. Для других скинов приложение сохраняет свой редактор либо добавляет этот слот. [Включение, дополнительные поля и серверный контракт](answer-editing.md).
