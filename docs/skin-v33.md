# Договор скина, версия 33

Добавлено необязательное `ChatSkin.spokenAnswer(markdown): string`. Скины предыдущих версий работают без изменений: диктор читает весь текст ответа без разметки, как раньше.

Зачем. Скрытая строка для экранного диктора (`aria-live`) строится из текста ответа, а не из того, что нарисовал `AgentText`. Если скин прячет часть ответа на экране (служебные блоки с данными для приложения), диктор всё равно прочитал бы её вслух. `spokenAnswer` получает текст ответа (Markdown) и возвращает его без того, что скин не показывает. Разметку после этого снимает SDK.

Подключение: скин отдаёт ту же функцию, которой `AgentText` прячет блоки.

```tsx
const mySkin: ChatSkin = {
  ...baseSkin,
  AgentText: MyAgentText,       // прячет блоки через hideServiceBlocks(markdown, streaming)
  spokenAnswer: (markdown) => hideServiceBlocks(markdown, false),
};
```

Если после `spokenAnswer` ничего не осталось, диктор слышит `labels.answerEmpty`.
