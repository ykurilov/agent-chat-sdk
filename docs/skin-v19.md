# Для авторов скинов: `ChatSkin` v19

Скин — внешний вид чата: компоненты без логики. Слой поведения (`@ykurilov/agent-chat-react`) сам собирает ленту
из них. Что нового:

- `ChatSkin` поднялся с версии 18 до **19**;
- у `Composer` появилось необязательное свойство `actions`.

**Скин версии 18 работает без правок.** Нет `actions` у скина — кнопок приложения у поля нет.

## Как приложение подключает кнопки

```tsx
<AgentChat
  …
  composerActions={(composer) => (
    <button disabled={!composer.canSend} onClick={() => composer.send("Проверь мою работу")}>
      Проверить работу
    </button>
  )}
/>
```

`composerActions` — готовый узел или функция от `ComposerHelper`: `value`, `setValue(text)`, `send(text?)`, `addFiles(files)`, `busy`, `blocked`, `canSend`. Свойство принимают `AgentChat`, `ChatWorkspace`, `AgentPanel` и `AgentSandbox.chatProps`. `send` работает по правилам кнопки «Отправить»: не во время ответа, не при остановке по лимиту, не до загрузки истории. Пока `canSend` ложно, `send` (с текстом и без) отказывает сразу и ничего не откладывает. Функцию `composerActions` чат вызывает при каждом рендере: она должна быть быстрой и без побочных эффектов, помощника не сохраняйте. `addFiles` кладёт файлы в поле, как скрепка; без плагина вложений ничего не делает.

## `Composer.actions`

`actions?: ReactNode` — кнопки приложения у поля ввода («Подсказка», «Проверь моё решение»). Узел готовый: слой
поведения собирает его из `AgentChat.composerActions`, скин только кладёт его на место.

- Положить рядом с кнопками поля (скрепка, микрофон, голосовой режим).
- В голосовом режиме кнопки оставить видимыми. Если поле ввода в этом режиме скрыто целиком, поставить их рядом с панелью режима: в Тандеме они стоят слева от кнопки «Стоп».
- Кнопки не должны сами что-то отправлять: приложение вызывает `send` у помощника `ComposerHelper`, который получает в `AgentChat.composerActions`.
- Нет `actions` — ничего не рисовать.

```tsx
const skin: ChatSkin = {
  …,
  Composer: ({ value, onValueChange, onSubmit, actions, … }) => (
    <form …>
      <textarea … />
      <div className="composer-actions">
        {actions}
        {/* скрепка, микрофон, отправка */}
      </div>
    </form>
  ),
};
```
