# Окно просмотра (для авторов скинов)

Картинки (вложения человека и картинки агента) и схемы открываются на весь экран. Окно рисует скин, а всё остальное делает слой
поведения. Часть `MediaViewer` необязательная: скин без неё работает, но картинки и схемы не открываются.

## Что делает слой поведения (`@ykurilov/agent-chat-react`)

- Собирает карусель: все картинки текущей ветки в порядке ленты, и человека, и агента. Схема открывается одна, без счётчика и стрелок.
- Держит открытый элемент: ключ — id вложения или `<messageId>:<номер блока>` у схемы. Повторный ключ отбрасывается.
- Пишет запись в историю браузера: жест «назад» на телефоне закрывает окно, а не страницу.
- Возвращает фокус на то, что открыло окно, когда окно закрыто.

## Что делает скин

```ts
interface MediaViewerProps {
  items: MediaViewerItem[];
  index: number;
  onIndexChange: (index: number) => void;
  onClose: () => void; // фокус вернёт слой поведения
}

type MediaViewerItem =
  | { kind: "image"; key: string; src: string; alt: string; width?: number; height?: number }
  | { kind: "diagram"; key: string; svg: string; source: string };
```

Скин обязан:

- закрывать окно крестиком, клавишей Esc и кликом по фону; Esc не должен всплывать выше (панель агента под окном не закрывается);
- листать стрелками ←/→ и свайпом; при нескольких элементах показывать стрелки и счётчик «3 из 12» (`viewer.counter`);
- масштабировать колесом и щипком, двигать перетаскиванием, возвращать «Вписать» (`viewer.fit`);
- держать фокус внутри окна, у окна `role="dialog"` и `aria-modal`;
- схему показывать векторным SVG, не превращая в картинку. SVG уже очищен пакетом схем, но кладите его как разметку только из этого поля.

Захват касания под перетаскивание включайте, только когда палец поехал: простое касание должно оставаться кликом.

Надписи — группа `viewer` словаря (`close`, `next`, `previous`, `fit`, `counter`). Эталон — `skins/tandem/src/media-viewer.tsx`.

## Что подключить в остальных частях скина

Окно открывают: `UserMessage` и `MessageEditor` (у вложений-картинок появился `onOpen(trigger)`), `GeneratedImages` (`onOpen` у готовой картинки),
`AgentText` (`onOpenDiagram`). Скин без `MediaViewer` может эти свойства просто не использовать.
