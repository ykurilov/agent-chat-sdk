# Data Model: Боковая панель агента

Новых таблиц и миграций нет. Всё ниже — типы в коде, тела запросов и записи `localStorage`/`sessionStorage`.

## ScreenPlace — место на экране (ядро и слой поведения)

| Поле | Тип | Правило |
|------|-----|---------|
| `description` | строка | для модели; на сервере обрезается до `placeMaxLength` (по умолчанию 1000) с «…», обрезка → журнал; пусто после обрезки пробелов = места нет |
| `data` | JSON-объект, необязательно | только для инструментов; JSON до 4 КБ, больше — отбрасывается с записью в журнал |

Живёт в браузере (`AgentPanelProvider`), уходит в теле каждого запроса хода, на сервере — только в памяти хода (`AgentToolsModel.place`, хвост запроса). В хранилище не пишется.

## AgentToolsModel (ядро, расширение)

| Поле | Было | Стало |
|------|------|-------|
| `profile`, `providerId` | ✔ | без изменений |
| `chatId`, `ownerId` | ✔ (017) | без изменений; `ownerId` — номер человека из `resolveUser` |
| `place` | — | `ScreenPlace \| null` — место хода (после обрезки) |
| `notifyDataChanged` | — | `(change: DataChange) => void` — сообщение об изменении данных |

Создаётся ядром раз на ход (`runTurn`), в том числе на продолжении после подтверждения.

## DataChange — сообщение об изменении данных

| Поле | Тип | Правило |
|------|-----|---------|
| `tag` | строка | 1–100 знаков, например `tasks` |
| `details` | JSON, необязательно | до 4 КБ в JSON |

В потоке: `{ type: "data-app-change", id, data: { tag, details? }, transient: true }`; `id` — новый UUID на каждый вызов. В хранилище и в сообщение не попадает.

## BrowserToolCall — вызов браузерного инструмента (поток и сервер)

Кусок потока: `{ type: "data-browser-call", id: toolCallId, data: { toolCallId, toolName, input, tabId }, transient: true }`.

Ожидающий вызов в памяти процесса (`PendingBrowserCalls`):

| Поле | Тип |
|------|-----|
| ключ | `chatId` + `toolCallId` |
| `tabId` | строка — вкладка, которая запустила ход |
| `resolve`/`reject` | ответ вкладки, срок, стоп |
| `timer` | `browserToolTimeoutMs`, по умолчанию 30 000 |

Состояния: `waiting` → `answered` (результат или ошибка вкладки) | `timed_out` | `aborted` (стоп, удаление чата, конец хода). После любого конечного — запись удаляется; повторный ответ → 409 `not_pending`.

Ответ вкладки: `{ tabId, output }` (JSON до 16 КБ) или `{ tabId, error: string }` (до 1000 знаков).

## AgentSettings (ядро, расширение)

| Поле | Тип | По умолчанию |
|------|-----|--------------|
| `browserTools` | `ToolSet` — описания без `execute` (`tool({ description, inputSchema, needsApproval? })`) | нет |
| `browserToolTimeoutMs` | число ≥ 1000 | 30 000 |
| `placeMaxLength` | число ≥ 100 | 1000 |

Имя браузерного инструмента, совпавшее с инструментом приложения или памяти, — ошибка при создании службы (объект) или при сборке набора хода (функция), как у памяти. Описание с `execute` — ошибка при создании службы.

## AgentAppBridge — связь чата с приложением (слой поведения)

| Поле | Тип | Назначение |
|------|-----|-----------|
| `tabId` | строка | номер вкладки из `sessionStorage` (`agent-chat:tab-id`) |
| `currentPlace()` | `() => ScreenPlace \| null` | место на момент запроса |
| `dataChanged(change)` | `(change: DataChange & { id: string }) => void` | раздаёт подписчикам; повтор `id` игнорирует |
| `browserCall(call)` | `(call) => Promise<{ output } \| { error }>` | исполняет функцию по имени; нет функции → `{ error: "Инструмент недоступен на этой странице" }` |

## Состояние панели (слой поведения)

| Что | Где | Ключ |
|-----|-----|------|
| открыта ли | `localStorage` | `agent-chat:panel:${api}:${userKey}` → `{ "open": boolean }` |
| открытый чат | `localStorage` через `useChatList({ rememberKey })` | `agent-chat:panel-chat:${api}:${userKey}` |
| номер вкладки | `sessionStorage` | `agent-chat:tab-id` |
| открытые вкладки (у дубликата вкладки свой номер) | `localStorage` | `agent-chat:tab-open:${tabId}`; снимается при уходе со страницы (`pagehide`) |
| исполненные браузерные вызовы | `sessionStorage` | `agent-chat:browser-calls-done` (последние 100 `toolCallId`) |
| розданные сообщения об изменении данных | `sessionStorage` | `agent-chat:app-changes-delivered` (последние 500 `id`) |
| место | память страницы | — |
| режим, ширина | свойства `AgentPanelProvider` | `mode: "overlay" \| "push"` (по умолчанию `overlay`), `width` (по умолчанию 420) |

Хранилище недоступно (приватный режим) — состояние держится только в памяти страницы, ошибок не показывается.

## Переходы панели

```text
закрыта ──кнопка / openChat / openNewChat / setOpen(true)──▶ открыта (чат)
открыта (чат) ──«к списку»──▶ открыта (список поверх) ──выбор / создание──▶ открыта (чат)
открыта ──«закрыть» / Esc / кнопка агента──▶ закрыта  (ответ идёт дальше, чат смонтирован)
открытый чат удалён ──▶ «Чат не найден» с переходом к списку (как ChatWorkspace)
смена userKey ──▶ состояние нового человека (прежнее не показывается)
```
