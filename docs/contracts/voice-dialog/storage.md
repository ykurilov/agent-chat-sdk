# Договор хранилища и учёта расходов (016)

Дополняет `docs/contracts/spending-limits/spending.md`.

- `UsageSource` = `"answer" | "compaction" | "speech"`. Хранилища принимают любой `source` (текст без ограничения): миграция для источника не нужна. Контрактные тесты хранилищ получают случай `speech`.
- Запись расхода озвучки — см. `data-model.md`. Сумма лимитов (`storage.sumUsage`) уже суммирует `costUsd` всех источников: озвучка попадает в лимиты без изменений в пакете лимитов; проверка — тест «озвучка приближает лимит».
- Необязательные методы `ChatStorage`: `setVoiceCut?`, `getVoiceChoice?`, `setVoiceChoice?` (сигнатуры в `data-model.md`). Есть в `storage-sqlite`, `storage-postgres` и in-memory; в контрактных тестах — блок «если метод есть».
- Чтение сообщений возвращает `voiceCut` (нет — `null`); формат сообщений (принцип IV) получает поле с той же версией формата: старые данные читаются без миграции значений.
- Владелец проверяется в хранилище (`ownerId`), как у остальных методов.
