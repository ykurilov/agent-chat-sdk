# Договор: говоримый текст (016)

Чистая функция без побочных эффектов в браузерной части пакета: приращения текста ответа → готовые к озвучке предложения.
`createSpokenText({ maxChars?, phrases? })` → `{ push(delta: string): SpokenSentence[]; finish(): SpokenSentence[] }`, где `SpokenSentence = { text: string; sourceStart: number; sourceEnd: number }` (`sourceStart`/`sourceEnd` — где предложение начинается и где кончается, после знака, в тексте, поданном в `push`; по ним позиция обрыва переводится в `partIndex`/`charOffset`). `sourcePositionAtSpoken(sentences, spokenChars)` — обратная карта: число озвученных знаков (предложения склеены через пробел) → позиция в тексте, внутри предложения пропорционально. Потолок знаков на ответ (`maxChars`, по умолчанию 1500): после него одна фраза «Дальше на экране.» и тишина.

## Правила

| В ответе | Звучит |
|---|---|
| Блок кода (```), в т.ч. с недописанным закрытием | «код на экране» один раз на блок |
| Таблица (строки с `\|`, разделитель) | «таблица на экране» один раз на таблицу |
| Строчный код `имя` | слово без обратных кавычек |
| Заголовки, списки, цитаты, жирный/курсив | смысловой текст без знаков разметки; пункты списка — отдельными предложениями |
| Ссылка `[подпись](адрес)` | подпись; голый адрес — не читается |
| Изображение | подпись, если есть, иначе ничего |
| Рассуждение модели, вызов инструмента, результат инструмента | не звучит (в функцию не подаются: хук отдаёт только текстовые части ответа) |
| Формулы, длинные списки идентификаторов | как обычный текст; читаемость — по живой проверке |

## Разбиение на предложения

- Предложение выпускается, когда встретился конец предложения (`.`, `!`, `?`, `…`, перевод строки) и следующий за ним пробел/символ, чтобы не резать «т. е.», «3.14», «стр. 5» — короткий список сокращений и числа; остаток без конца предложения выпускается в `finish()`.
- Первое предложение выпускается раньше остальных: если после ≈ 12 слов нет конца предложения, режется по запятой/тире; цель — звук как можно раньше.
- Границы блоков не зависят от того, как ответ порезан на куски (тест с разрезом в каждой позиции).
