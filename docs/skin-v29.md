# Для авторов скинов: ChatSkin v29

Все добавления необязательные. Скины версии 28 работают без правок.

`Composer.options?: ComposerOptions` - общий договор выбора вида поля и дополнительных элементов приложения. Приложение передаёт его через `AgentChat.composerOptions`; `ChatWorkspace` и `AgentPanel` наследуют свойство. Варианты: `compact`, `standard`, `extended`. Скин вправе не поддерживать варианты; Одуванчик поддерживает все три, по умолчанию `standard`.

В `ComposerOptions`:

- `context: { label, onPick? }` - подпись контекста и открытие выбора;
- `projects: [{ id, label, onPick }]` - выбор проекта в меню добавления;
- `contextAttachments: [{ id, label, onRemove? }]` - плашки выбранного контекста;
- `tools: [{ id, label, description?, enabled, onChange }]` - управляемые приложением переключатели инструментов;
- `reasoningVisibility: { value, onChange }` - отображение хода мысли. `AgentChat` даёт локальное состояние, если приложение не передало своё. Права сервера этот переключатель не расширяет.

Проекты и инструменты принадлежат приложению: `onPick`/`onChange` меняет его состояние, а приложение применяет выбор в серверной конфигурации/контексте хода. Скин не вызывает скрытого API переключения инструментов и не превращает проект в загруженный файл.

`ModelChoiceView.providers[].models[]` дополнен необязательными `group`, `description`, `tags`, `price: { inputPerMillion, outputPerMillion }`. Числа - базовые USD за миллион токенов, отдельно вход и выход. Это цены выбранного провайдера из каталога, без расчёта текущего часа, кэша и длинного контекста. Сервер `buildModelMenu` отдаёт их из `ModelProfile.pricing`; `ModelProfile.menu` позволяет задать группу, описание и метки. Хук `useModelChoice` сохраняет их при передаче скину. Старый сервер без новых полей также поддерживается. Без группы Одуванчик разделяет модели по наличию поддержки изображений.

`AgentMessage.modelDetails?: { modelId, providerId, modelName?, providerName?, reasoning? }` - настройки именно этого ответа. `AgentChat` передаёт их при `answerDetails` или расширенном виде поля; имена берёт из каталога, а уровень - из `message.metadata.reasoningLevel`. Текущий выбор модели не подменяет историю ответа. У старого ответа уровень может быть неизвестен - его пропускают. Скины без поддержки свойства ничего не меняют.

Новые завершённые ответы сохраняют уровень в служебной части хранилища `data-answer-reasoning`; `toAgentChatMessage` убирает эту часть и отдаёт уровень в метаданных. Части для модели и экрана остаются прежними, миграция базы не требуется. `modelDetails: false` скрывает уровень вместе с именем модели. Это уровень, заданный для хода, а не отчёт об эффективном бюджете каждого обращения к запасному провайдеру.

`WorkSteps` в состоянии `live` получает необязательный `completed: [{ phrase, failed, icon? }]`. Завершённые шаги текущей группы доступны до конца ответа. Одуванчик показывает их с галочками, текущий шаг - со сферой. Старые скины сохраняют живую строку.
