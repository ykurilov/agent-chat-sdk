# Для авторов скинов: `ChatSkin` v26

Что нового — готовая картинка из библиотеки приложения (пакет `@ykurilov/agent-chat-image-library`, вызов `show_image`).
Она приходит в тот же `GeneratedImages`, что и картинки `generate_images`, с двумя новыми полями.

- `ChatSkin` поднялся с версии 25 до **26**;
- `GeneratedImagesView.wide?: boolean` — рисовать картинку по ширине ответа со своей пропорцией, а не плиткой сетки.
  Точная пропорция — `width` и `height` у готовой картинки, `aspectRatio` — ближайшая обычная (1:1, 3:2, 2:3, 16:9, 9:16);
- у готовой картинки `caption?: string` — видимая подпись под ней (название из каталога). `alt` — по-прежнему текст для
  незрячих и для окна просмотра;
- пока вызов идёт, приходит пустой вид (`items: []`, `wide: true`): заглушку «картинка создаётся» не рисуйте.

**Скин версии 25 работает без правок:** картинка рисуется плиткой сетки пропорции `aspectRatio` без подписи. Если
настоящая пропорция другая, края могут слегка обрезаться. Скин Тандема `wide` и `caption` уже рисует. Подробно —
[image-library.md](./image-library.md).
