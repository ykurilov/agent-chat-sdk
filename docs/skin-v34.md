# Договор скина, версия 34

Добавлено необязательное `AgentMessage.emptyText?: string` — строка вместо ответа без текста. Скины предыдущих версий работают без изменений: они решают по `empty`, как раньше.

Зачем. Ответ без текста рисовался одной и той же пустой карточкой с «Модель не дала ответа», хотя причины разные. Ответ, закрытый ради поправки, продолжается следующим ответом. «Стоп» до первого слова — это решение человека, а не молчание модели. Теперь причину выбирает слой поведения, а скин только показывает строку.

Что приходит скину:

| Ответ | `empty` | `emptyText` |
|---|---|---|
| есть текст | `false` | нет |
| закончен и закрыт ради поправки, есть шаги | `false` | `""` |
| закончен и закрыт ради поправки, показать нечего (ни частей, ни ошибки, ни меток, ни переключателя веток) | ответ не рисуется совсем | — |
| остановлен до первого слова | `true` | `labels.answerStoppedEmpty` («Ответ остановлен до начала») |
| оборвался до первого слова (обрыв связи, перезапуск) | `true` | `labels.answerInterruptedEmpty` («Ответ оборвался до начала») |
| остановлен или оборвался после начала работы (раздумье, вызов инструмента, файл), без текста | `true` | `""` |
| закончен, модель промолчала | `true` | `labels.answerEmpty` |
| ошибка без текста | `true` | `""` (объясняет `notice`) |

«Стоп» при ждущей поправке — обычный остановленный ответ: строка или отметка «Остановлено» видны. «До начала» экран и диктор понимают одинаково: нет текста, раздумья, вызова инструмента (подсказки ответа не в счёт), файла и события приложения.

Пустой текст законченного ответа (одни пробелы) больше не приходит в `children`: тела у такого ответа нет. У ответа, закрытого ради поправки, без текста нет и `modelDetails`.

Что делает скин версии 34:

- `emptyText` непустой — показать эту строку вместо `labels.answerEmpty`; отметку «Остановлено» или «Ответ прерван» рядом не повторять;
- `emptyText === ""` — без строки;
- `emptyText` есть (в том числе `""`) — кнопку «Скопировать» не показывать;
- ряд кнопок, в котором ничего нет, скрыть, чтобы не оставалось пустой полосы;
- ответ без тела (только ряд кнопок) — без аватара, место под ним оставить.

```tsx
AgentMessage: ({ status, children, empty, emptyText, ...props }) => {
  const labels = useChatLabels();
  const emptyLine = emptyText ?? (empty ? labels.answerEmpty : "");
  const textless = empty || emptyText !== undefined;
  // emptyLine — строкой под частями ответа; textless — без «Скопировать».
}
```

Новые надписи `answerStoppedEmpty` и `answerInterruptedEmpty` необязательны в своём словаре: без них берутся русские или английские по `locale`. Диктор (`announcement`) говорит то же, что видно: «Ответ остановлен до начала», а у ответа, закрытого ради поправки, молчит до ответа на неё.
