# Для авторов скинов: `ChatSkin` v27

Что нового — служебная строка без пузыря перед ответом агента: «Агент написал первым — человек молчал 1 ч 7 мин».

- `ChatSkin` поднялся с версии 26 до **27**;
- `ServiceLine?: ComponentType<{ text: string }>` — тихий мелкий текст по центру ленты, как «История сжата». `text` —
  готовая строка, без разметки. Это не сообщение человека и не плашка: кнопок, пузыря и «Изменить» у неё нет.

Строка появляется, только когда сервер отдал пометку приложения (право чата `appNotices`) и страница дала ей текст
(`noticeLines` у `AgentChat`). Подробно — [flows.md](./flows.md), раздел «Тестовый чат».

**Скин версии 26 работает без правок:** пометок не видно, лента как раньше. Скин Тандема `ServiceLine` уже рисует.
