# Договор скина, версия 36

Добавлено необязательное `ComposerAttachmentItem.progress?: number` — сколько файла уже отправлено, от 0 до 1. Скины предыдущих версий работают без изменений.

Зачем. Человек добавлял пять фотографий по несколько мегабайт, и у всех плашек было одно «Загружается…». Не видно, идёт ли загрузка, сколько ждать и какие файлы уже в пути.

Как теперь работает плагин вложений:

- У `fetch` нет прогресса отправки. Поэтому файл уходит через `XMLHttpRequest`, только когда приложение не передало свой `fetch` в настройки плагина и глобальный `fetch` страницы — родной, браузерный.
- `progress` есть только у файла, который грузится прямо сейчас: `0` в начале, дальше растёт с шагом в 1 %. Поле перерисовывается не чаще, чем меняется целый процент.
- Файл ждёт очереди (поле грузит по два сразу) — `progress` нет. Так видно, какие файлы уже идут.
- Сервер ответил «занят» — на время паузы `progress` пропадает, повтор начинается с `0`.
- Готовый файл и файл с ошибкой — без `progress`.
- Приложение передало свой `fetch` или подменило глобальный (токен авторизации, перехватчик, мок в тестах) — файл уходит через него, как раньше, `progress` нет: плашка выглядит как до версии 36. Подмена узнаётся по имени функции и её исходному коду; обёртку-`Proxy` вокруг родного `fetch` плагин не отличит — такому приложению стоит передать свой `fetch` в настройки.
- 100 % значит «браузер всё отправил». Сервер ещё может разбирать файл: вместо «100 %» скин показывает «Загружается…», пока сервер не ответит, — чтобы не казалось, что загрузка застряла.

Что делает скин версии 36, пока у файла есть `progress`:

- полоса или кольцо прогресса с `role="progressbar"`, `aria-valuemin="0"`, `aria-valuemax="100"`, `aria-valuenow` — целый процент;
- имя полосы для диктора — `labels.uploadProgress.label(fileName)` («Загрузка «кот.png»»);
- по желанию — видимый процент `labels.uploadProgress.percent(percent)` («46 %»); на 100 % вместо него — «Загружается…».

```tsx
{item.status === "uploading" && item.progress !== undefined && (
  <span role="progressbar" aria-label={labels.uploadProgress.label(item.name)}
    aria-valuemin={0} aria-valuemax={100} aria-valuenow={Math.round(item.progress * 100)} />
)}
```

Надписи `uploadProgress` необязательны в своём словаре: без них берутся русские или английские по `locale`.

Одуванчик показывает процент у имени файла и тонкую полосу по низу плашки. Тандем ставит такую же полосу и процент в плашку поля `@tandem/ui`: у самого поля прогресса нет. Процент у Тандема — вместо подписи под именем файла или вместо значка ожидания на миниатюре картинки. На 100 % оба скина показывают «Загружается…» (Тандем — прежнюю подпись или значок ожидания).
