# Картинки Markdown в Swift

С 0.93.0 `AgentChatMarkdown` и ответы внутри `AgentChatView` показывают
`![подпись](адрес)` и `![подпись](адрес "заголовок")`. Отдельная строка с
картинкой становится блоком; картинка внутри абзаца разделяет его на текст,
картинку и следующий текст. В списках и цитатах картинки также видны. Кодовые
блоки и строчный код не превращаются в картинки. Незавершённая разметка остаётся
текстом до закрывающей скобки. Alt показывается подписью и доступным именем.

## Загрузчик приложения

Добавьте модификатор к общему предку чата или к отдельному ответу:

```swift
AgentChatView(client: client)
    .agentChatImageLoader { address in
        try await fileService.loadImage(originalAddress: address)
    }
```

Сигнатура:

```swift
public typealias AgentChatImageLoader = @Sendable (_ address: String) async throws -> Data
```

Также доступен `EnvironmentValues.agentChatImageLoader`. Модификатор наследуется
всеми ответами внутри представления. Адрес передаётся без изменений: `/tmp/...`,
`file:///...`, `~/...` не превращаются в URL на телефоне. Приложение само проверяет
права, сопоставляет путь с адресом своего сервера и добавляет ключ доступа.
Не встраивайте секреты в Markdown или общедоступные адреса. SDK не читает
локальные файлы по адресам из ответа модели.

Без загрузчика HTTP(S) загружается через `URLSession.shared` (проверяется успешный
HTTP-статус и декодирование картинки). Для остальных адресов видна только подпись,
без ошибки и сетевого запроса. Подмена загрузчика заменяет и HTTP(S)-путь;
если ему требуется обычная HTTP-загрузка, приложение выполняет её само.

## Геометрия и ограничения

Под поддерживаемую картинку с начала загрузки отводится вся ширина ответа и
рамка 4:3. Изображение вписывается с сохранением собственных пропорций; у широких
и высоких картинок остаются поля. Декодирование и ошибка не меняют высоту рамки,
чтобы не двигать ленту. Подпись выделяется и копируется как текст; существующее
копирование всего ответа остаётся исходным Markdown. При исчезновении блока
задача отменяется, поздний результат не применяется. Загрузчик приложения должен
кооперативно поддерживать отмену. Повторное появление блока может повторить загрузку;
кэширование авторизованных файлов относится к загрузчику приложения.

Полноэкранного просмотра по нажатию в этой версии нет. Поддерживается inline
синтаксис картинок с адресом, а не reference-style определения `[image]: ...`.
Новая ветка `.image(alt:address:title:)` добавлена в `ChatMarkdownBlock`: если
приложение само исчерпывающе переключает этот enum, добавьте её обработку.
Веб-скины и протокол сервера не меняются, миграций базы нет.
