# Помощники

Помощник — узкий агент внутри основного: у него своя инструкция, своя модель и свои инструменты. Основной агент
отдаёт ему задание («найди, в каком году вышел фильм») и получает только короткий итог. Человек при этом видит весь
путь помощника: какие инструменты он вызвал и что нашёл. Основной агент не засоряется чужими шагами, а ответ
получается дешевле и точнее.

Помощники встроены в ядро (`@ykurilov/agent-chat-core`), отдельный пакет не нужен. Чтобы помощник работал в фоне,
добавляется `@ykurilov/agent-chat-background` (см. [Фоновые задачи](background.md)).

## Включить

```ts
createChatHandler({
  …,
  agent: {
    instructions: appInstructions,
    tools: appTools,
    helpers: {
      researcher: {
        description: "Ищет факты в интернете. Зови, когда нужен поиск по нескольким источникам.",
        instructions: "Ты исследователь. Найди факт, проверь по второму источнику, ответь коротко.",
        model: { providerId: "openrouter", modelId: "ваша-дешёвая-модель" }, // модель из каталога приложения
        tools: webTools.tools,
        maxSteps: 6,
      },
    },
  },
});
```

Основной агент видит инструмент `helper_researcher` с вашим `description` и одним полем — заданием.

| Поле | Что | По умолчанию |
|---|---|---|
| `description` | Когда звать помощника; уходит основному агенту | обязательно |
| `instructions` | Инструкция помощника | обязательно |
| `model` | Модель из каталога приложения | обязательно |
| `tools` | Инструменты помощника (тот же вид, что у `agent.tools`) | нет |
| `maxSteps` | Предел шагов помощника; последний шаг — итог без инструментов, вызов на нём не выполняется | 10 |
| `background` | `true`: помощник работает фоновой задачей | `false` |

У помощника не бывает браузерных инструментов и других помощников.

## Что видит человек, что видит модель

- Человек: строка помощника в ленте с заданием, шагами (вызов инструмента, вход, коротко результат) и итогом.
  Результат каждого шага обрезан до 2 КБ.
- Модель основного агента: только итоговый текст помощника.

## Подтверждения

Если инструмент помощника просит подтверждения (`needsApproval`), помощник встаёт на паузу, а в строке появляются те
же кнопки «Разрешить / Отклонить». После ответа помощник продолжает с того же места. Рассуждения модели (если они
есть) возвращаются в запрос без изменений, поэтому и модели Anthropic через OpenRouter продолжают без ошибок.

## Кэш модели

Начало запроса помощника стабильно: инструкция, описание инструментов и задание идут в одном порядке. Повторный
вызов того же помощника берёт префикс из кэша провайдера. В живой проверке второй вызов взял из кэша 3456 токенов
из 3478.

## Скин

Строку помощника рисует `HelperCallRow` скина (договор `ChatSkin` v18, см. [Скины](skin-v18.md)). Нет у скина —
помощник показывается обычной строкой инструмента.
