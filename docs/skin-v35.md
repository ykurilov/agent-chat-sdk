# Договор скина, версия 35

Добавлено необязательное `Composer.pendingSend?: { onCancel: () => void }` — «Отправить», нажатое во время загрузки файлов. Скины предыдущих версий работают без изменений.

Зачем. Человек вставлял скриншот, пока шла загрузка, нажимал «Отправить» или Enter — нажатие молча пропадало. После загрузки сообщение не уходило, приходилось жать снова. Люди думали, что картинку без текста не отправить.

Как теперь работает слой поведения:

- Пока файлы грузятся и ни один не упал, `canSubmit` (и `canSteer` во время ответа) — `true`: скин пропускает нажатие к `onSubmit`.
- Нажатие во время загрузки запоминается. Как только все файлы загрузились, сообщение уходит само — с текстом и файлами, что в поле на этот момент. Во время ответа агента оно уходит поправкой, если поле принимает поправки, иначе ждёт конца ответа.
- Повторное нажатие и Enter во время ожидания ничего не шлют.
- Загрузка упала — ничего не уходит, ожидание снято. Надпись у поля (`attachments.notice`) начинается с `labels.sendAfterUpload.notSent` («Сообщение не отправлено.»), дальше — причина от плагина вложений.
- Человек убрал все файлы — ожидание снимается, как «Не отправлять»: текст сам не уходит.
- Отправка стала невозможна (лимит, чат закрыт) — ожидание снимается молча: причину объясняет своя надпись.

Что делает скин версии 35, пока `pendingSend` есть:

- у кнопки отправки или рядом — строка `labels.sendAfterUpload.waiting` («Отправим, как только загрузятся файлы») в области `role="status"`; область стоит в странице заранее, пока есть вложения;
- кнопка отправки занята (`aria-busy`), но не `disabled`: фокус с неё не слетает; повторное нажатие и Enter не зовут `onSubmit`;
- кнопка `labels.sendAfterUpload.cancel` («Не отправлять») зовёт `onCancel` — человек передумал; отправить можно снова вручную.

```tsx
Composer: ({ pendingSend, onSubmit, canSubmit, ...props }) => {
  const labels = useChatLabels();
  const submit = () => { if (canSubmit && !pendingSend) onSubmit(); };
  // строка ожидания: <span role="status">{pendingSend ? labels.sendAfterUpload.waiting : ""}</span>
  // «передумал»: {pendingSend && <button onClick={pendingSend.onCancel}>{labels.sendAfterUpload.cancel}</button>}
}
```

Скин до версии 35: если он пропускает нажатие при `canSubmit === true`, нажатие запоминается и уходит само, только без строки ожидания. Скин, который сам закрывает отправку на время загрузки (так делает поле `Composer` из `@tandem/ui`), продолжит её закрывать.

Надписи `sendAfterUpload` необязательны в своём словаре: без них берутся русские или английские по `locale`.
