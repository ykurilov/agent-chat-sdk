# Для авторов скинов: `ChatSkin` v24

Что нового — отметка «Не доставлено» у ответа агента, который не дошёл до человека (канал закрыт, человек заблокировал
бота).

- `ChatSkin` поднялся с версии 23 до **24**;
- у ответа агента (`AgentMessage`) появилось необязательное `undelivered`: показать серую отметку;
- в словаре — `labels.answerUndelivered` («Не доставлено» / «Not delivered»).

**Скин версии 23 работает без правок:** отметки просто нет. Скин Тандема отметку пока не рисует.
