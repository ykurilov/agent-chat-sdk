# Для авторов скинов: `ChatSkin` v28

Что нового — значки шагов в простом виде работы агента и заголовки раздумий («Продумываю правила игры» вместо
«Думал 3 сек»). Всё необязательное.

- `ChatSkin` поднялся с версии 27 до **28**;
- `WorkStepsView` (`state: "live"`): `icon?: StepIcon` — значок текущего шага;
- `WorkStepsView` (`state: "done"`):
  - `icons?: StepIcon[]` — ряд значков свёрнутой строки, по значку на шаг, не больше 8;
  - `moreIcons?: number` — сколько не влезло, подпись `labels.workView.moreSteps(n)` («+3»);
  - `items?: Array<{ icon; phrase; failed }>` — раскрытый список: вызовы и раздумья (заголовок или
    `labels.workView.thought(ms)` — «Думал 4 сек»). Прежний `steps` — только вызовы, для скинов 23–27;
- `Reasoning.title?: string` — заголовок раздумья для подробного вида: показать вместо «Думал N сек».

`StepIcon` — строка вида шага, не картинка: `thinking`, `read`, `edit`, `search`, `web`, `skill`, `mcp`, `image`,
`video`, `check`, `snapshot`, `run`, `memory`, `helper`, `task`, `tool`. Приложение может дать свой вид строкой —
незнакомый рисуйте общим значком (`tool`). Значки — тихие, цвета приглушённого текста, размер строки (около 14 px);
ряд — в одну строку, без переноса и на телефоне.

**Скин версии 27 работает без правок:** шаги без значков, список — только вызовы, раздумья — «Думал N сек». Скин
Тандема всё это уже рисует.
