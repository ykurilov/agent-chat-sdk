# Фоновые задачи

Долгая работа не держит разговор. Агент запускает задачу («собери отчёт», «исследуй тему»), в ленте появляется
карточка с таймером и кнопкой «Отменить», человек пишет дальше. Когда задача кончилась, в чат приходит служебное
сообщение «Задача готова» с итогом, и агент отвечает по нему. Сервер перезапустился посреди задачи — после старта она
подбирается и доделывается.

Это отдельный пакет `@ykurilov/agent-chat-background`. Без него ничего не меняется.

## Включить

```bash
pnpm add @ykurilov/agent-chat-background
```

```ts
import { createBackgroundTasks, backgroundTool } from "@ykurilov/agent-chat-background";
import { sqliteTaskStore } from "@ykurilov/agent-chat-background/sqlite";

const background = createBackgroundTasks({
  store: sqliteTaskStore("./data/chat.db"),
  tools: { build_report: backgroundTool({ description, inputSchema, title, run }) },
});

createChatHandler({ …, background }); // или createChatServer({ …, background })
```

Полный список настроек, значения по умолчанию, хранилища (память, SQLite, Postgres) и примеры — в
[README пакета](../packages/background/README.md). Коротко: одновременно идёт до 3 задач человека, предел времени
30 минут, аренда задачи 30 секунд.

## Два вида задач

- **Фоновый инструмент** — ваша функция. После перезапуска сервера по умолчанию получает «прервана»; если работа
  безопасна для повтора, `rerunAfterRestart: true`.
- **Фоновый помощник** — [помощник](helpers.md) с `background: true`. Его шаги сохраняются, после перезапуска он
  продолжает с места остановки, а уже сделанные вызовы инструментов не повторяются.

## Подтверждение и отмена

- Инструмент или помощник просит разрешения — задача встаёт на паузу (`awaiting_approval`), место не занимает, а
  в чате появляется служебное сообщение с кнопками. Ответили — работа идёт дальше.
- «Отменить» в карточке (вкладка или мессенджер) или `cancel_task` агента: работа получает `signal`.
- Больше `maxRunningPerUser` задач сразу — агент получает «слишком много задач» и ждёт или отменяет лишнее.

## Что видно на вкладке

Карточку задачи (`TaskCard`) и служебное сообщение (`AgentNoticeView`) рисует скин (`ChatSkin` v18, см.
[Скины](skin-v18.md)). Статус карточки и итог вкладка обновляет сама, без перезагрузки страницы. HTTP-адреса:
`GET {base}/:chatId/tasks` — список, `POST {base}/:chatId/tasks/:taskId/cancel` — отмена,
`POST {base}/:chatId/tasks/:taskId/approval` — ответ на вопрос (`{ decision: "allow" | "deny", approvalId }`).

## Несколько копий сервера

Копия держит задачу по аренде и продлевает её. Копия упала — аренда истекает, другая подбирает задачу. Итог
доставляется в чат хотя бы один раз; повторная пачка идёт с тем же ключом, дубля в чате не будет.
