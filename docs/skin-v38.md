# Договор скина, версия 38

Панель агента: видимая подпись кнопки закрытия на телефоне. Новых пропсов нет, только надпись в словаре. Скины предыдущих версий работают без изменений: на телефоне у кнопки закрытия остаётся один значок.

Зачем. На экране до 640 px панель закрывает всю страницу. Значок «×» в углу не говорит, куда человек попадёт после нажатия. Подпись «Закрыть» — или своя у приложения, например «Назад к уроку», — говорит.

## Надпись `agentPanelCloseText`

- Необязательна в своём словаре. Без неё берётся «Закрыть» или «Close» по `locale`.
- Приложение задаёт своё через `ChatLabelsProvider`: `{ ...russianLabels, agentPanelCloseText: "Назад к уроку" }`.

## Что делает скин `AgentPanel`

- Экран ≤ 640 px, панель на весь экран: у кнопки закрытия рядом со значком видна подпись `labels.agentPanelCloseText`. Имя кнопки — эта же подпись: `aria-label` не ставить, иначе экранный диктор прочитает не то, что видно.
- Широкий экран: только значок, имя кнопки — `labels.agentPanelClose`, как раньше.
- Касание кнопки — не меньше 44×44 px. Длинная подпись не уводит шапку в горизонтальную прокрутку: кнопка не шире половины шапки, лишнее обрезается многоточием.
- Узкий экран узнаётся через `matchMedia` в первой же отрисовке на клиенте, поэтому подпись видна сразу. При отрисовке на сервере первый кадр — без подписи, она появляется сразу после гидратации.

```tsx
const narrow = useMediaQuery("(max-width: 640px)");
<button aria-label={narrow ? undefined : labels.agentPanelClose} onClick={onClose}>
  <X aria-hidden="true" />
  {narrow && <span className="truncate">{labels.agentPanelCloseText}</span>}
</button>
```

## Одуванчик и Тандем

Оба скина рисуют подпись на экране ≤ 640 px, кнопка не шире половины шапки, длинная подпись — с многоточием. В Одуванчике у такой кнопки атрибут `data-captioned`: ширина по подписи, поля по 12 px.

## Слой поведения (не договор скина)

Вместе с этой версией в `@ykurilov/agent-chat-react/panel` появились:

- `useAgentPanel().openSubject(key)` — открыть панель на чате объекта (`POST {api}/subject`). Пока чат ищется, в панели вид загрузки чата. При отказе сервера в панели его текст и «Повторить». Шапка — название чата из его истории, даже если чата нет в списке.
- `useAgentPanel().activeChatId` — id открытого чата, только для чтения. Пока ищется чат объекта — `null`.
- Проп `launcher` у `AgentPanel` (по умолчанию `true`). `<AgentPanel launcher={false} />` убирает встроенную плавающую кнопку. Тогда нужна своя кнопка через `useAgentPanelLauncher()`, иначе фокусу после закрытия панели может быть некуда вернуться. `AgentPanelLauncher` в скине остаётся обязательным: без `launcher={false}` его рисуют, как раньше.
- `useAgentPanelLauncher()` — своя кнопка вызова в любом месте страницы: `<button {...useAgentPanelLauncher()}>`.
- Фокус после закрытия панели — туда, откуда её открыли: на нажатую кнопку вызова или на элемент, который был в фокусе при открытии из кода. Его уже нет или не видно — на свою кнопку вызова, иначе на встроенную.
- Чат объекта не запоминается как открытый чат панели: после перезагрузки панель на последнем обычном чате. Пока он ищется, панель не выбирает и не создаёт другой чат, а значок занятости на кнопке не горит.
