# Для авторов скинов: `ChatSkin` v20

Скин — внешний вид чата: компоненты без логики. Слой поведения (`@ykurilov/agent-chat-react`) сам собирает ленту
из них. Что нового:

- `ChatSkin` поднялся с версии 19 до **20**;
- появился необязательный компонент `ChatClosedNotice` — надпись закрытого чата;
- у `ChatListSkin.ChatWorkspace` свойство `list` стало необязательным;
- у строки списка `ChatListItemView` появилось необязательное `closed` — закрытый чат.

**Скин версии 19 работает без правок.** Нет `ChatClosedNotice` — закрытие показывает `ErrorNotice` с текстом приложения.

## `ChatClosedNotice`

`ChatClosedNotice?: ComponentType<{ id: string; code: string; message: string }>` — чат закрыт (заявка отправлена, урок
сдан). Рисуется в слоте `Layout.notice`, пока чат закрыт. Поле ввода в это время получает `sendingBlocked` и
`sendingBlockedReasonId` — это `id` надписи.

- `message` — слова приложения, до 300 знаков. Показывать только как текст, без разметки.
- `code` — для оформления (например, `data-closed-code`), человеку не показывать.
- `id` повесить на элемент надписи; элемент с `role="status"` и `tabIndex={-1}`.
- Кнопок в надписи нет: открыть чат снова может только приложение.

```tsx
const skin: ChatSkin = {
  …,
  ChatClosedNotice: ({ id, code, message }) => (
    <div id={id} role="status" tabIndex={-1} data-closed-code={code}>
      {message}
    </div>
  ),
};
```

В Тандеме — `TandemChatClosedNotice`: спокойная справка того же вида, что надпись о лимите.

## `ChatWorkspace` без списка

Если у открытого чата запрещено право `chatList`, слой поведения не передаёт `list`. Тогда не рисовать список, его
заголовок, кнопку «Чаты» и выезжающую панель — только чат. Место чата в разметке лучше не менять: иначе чат загрузится
заново.

## Пометка «Закрыт» в списке

`ChatListItemView.closed?: { code, message }` — чат закрыт. Поставить рядом с названием пометку с надписью
`chatListClosed` из `useChatLabels()` («Закрыт»), а `message` показать подсказкой. Нет `closed` — чат открыт. Скин без
пометки работает: строка просто без неё. В Тандеме у строки появляется `data-chat-closed`.

`chatListClosed` — новое обязательное поле словаря `ChatLabels`. Свой словарь, собранный целиком, должен его добавить;
словарь поверх `russianLabels` получает его сам.
