# @ykurilov/agent-chat-reply-check

Проверки готового ответа агента для `replyChecks` службы чата. Работают в любом приложении, сценарий не нужен.

```ts
import { foreignWords, unknownLinks } from "@ykurilov/agent-chat-reply-check";

createChatService({
  replyChecks: [
    foreignWords({ script: "cyrillic", knownNames: ["Excel", "Telegram"] }),
    unknownLinks({ appDomains: ["apps.example.com"] }),
  ],
});
```

## `foreignWords({ script, language?, knownNames?, maxLengthRatio? })`

Ищет чужие слова: иероглифы и другие письменности (всегда), слово из соседней письменности вне названий
(латиница в русском ответе, кириллица в английском), латинскую букву внутри русского слова.
Законны слова из `seenTexts` (инструкция, сценарий, реплики человека), `knownNames`, сокращения из заглавных и названия
с большой буквы посреди фразы.

- `script` — письменность ответа: `"cyrillic"` или `"latin"`. Язык «русский» не зашит.
- `language` — как назвать язык в инструкции переписки («по-русски», «по-немецки»). По умолчанию: кириллица — «по-русски»,
  латиница — «по-английски».
- `maxLengthRatio` — во сколько раз переписанный ответ может быть длиннее исходного (1.5). Короче 0.6 исходного не принимается.

Одна переписка моделью. Не вышло — уходит вариант с меньшим числом чужих слов (при равенстве — исходный).

## `unknownLinks({ appDomains?, labels? })`

Находит адреса (`http(s)://`, `www.`, домен с путём), которых нет в `seenTexts`. Законны и голые адреса из них, и короткое
имя на домене приложений, если человек назвал это имя (`sveta-nails` → `sveta-nails.apps.example.com`). Домен приложений
задаёт `appDomains` или шаблон в знакомых текстах («адрес.apps.example.com»). Одна переписка, остаток вырезается кодом.

Ответ был целиком выдуманной ссылкой — уходит запасная фраза `labels.linkOnlyReply`, в `note` — «запасная фраза».
Слова: `russianReplyCheckLabels` (по умолчанию), `englishReplyCheckLabels` или свои (`Partial<ReplyCheckLabels>`).

## Кэш и журнал

Инструкции переписки постоянные: меняется только текст запроса после них. Итог каждой проверки возвращается в `note`
(`чужие слова: итог=… было=… осталось=…`); расход переписки ядро пишет как `answer_correction`.
